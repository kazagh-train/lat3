# BumiNadi — Website Edukasi SDG 13 (7 Halaman)

Proyek website statis untuk UTS Pemrograman Web dengan topik perubahan iklim dan SDG 13.

## Daftar halaman
1. `index.html` — Beranda: pengenalan website dan perubahan iklim, pengantar SDG 13, ringkasan penyebab/dampak/solusi, fakta singkat, dan tombol navigasi.
2. `edukasi.html` — Mengenal Perubahan Iklim: pengertian perubahan iklim dan pemanasan global, cuaca vs iklim, efek rumah kaca, gas rumah kaca, dan penyebab umum.
3. `penyebab.html` — Penyebab dan Jejak Karbon: bahan bakar fosil, industri, transportasi, pertanian, deforestasi, pengertian jejak karbon, dan contoh sehari-hari.
4. `dampak.html` — Dampak Perubahan Iklim: suhu, banjir, kekeringan, cuaca ekstrem, permukaan laut, kesehatan, pertanian, ekosistem, dan konteks Indonesia.
5. `mitigasi.html` — Mitigasi Perubahan Iklim: energi terbarukan, efisiensi energi, transportasi rendah emisi, perlindungan hutan, dan peran pemerintah/masyarakat.
6. `aksi-iklim.html` — Adaptasi dan Aksi Iklim: kesiapsiagaan, hemat air, pengelolaan sampah, dan aksi di rumah/kampus/masyarakat.
7. `tentang.html` — Tentang dan Referensi: latar belakang, tujuan, manfaat, sasaran, identitas kelompok, SDG 13, dan sumber informasi.

## Teknologi
- HTML5 semantik dan CSS3 eksternal.
- CSS Grid, Flexbox, media queries, serta menu responsif sederhana dengan JavaScript.
- Tidak menggunakan framework, backend, atau database.
- Identitas visual BumiNadi: logo SVG khusus, ilustrasi bumi, atmosfer, industri/emisi, pesisir, energi bersih, dan aksi komunitas.
- Seluruh ilustrasi disimpan lokal di folder `images/` sebagai SVG, sehingga tetap tampil saat website dibuka offline dan ikut terunggah ke GitHub.
- Warna utama hijau hutan, teal, krem hangat, dan aksen kuning; layout responsif dan navigasi seluler.

## Cara menjalankan
Ekstrak ZIP, lalu buka `index.html` di browser. Untuk pengembangan, gunakan editor kode dan pastikan folder `css` tetap berada di samping file HTML.

## Sebelum dikumpulkan
- Isi nama, NIM, dan pembagian tugas pada `tentang.html`.
- Pastikan konten sesuai instruksi dosen dan dapat dijelaskan oleh anggota kelompok.
- Uji semua halaman pada desktop, tablet, dan ponsel.
- Periksa tautan navigasi, ejaan, kontras, dan tampilan layar kecil.
- Tambahkan sumber khusus yang benar-benar digunakan beserta tanggal akses bila diminta dosen.
